## 요청 반영

- **모델**: 수감자 12명을 큰 머리·짧은 팔다리·큰 부츠의 SD 비율로 재구성했습니다. 3/4 방향 얼굴, 캐릭터별 눈·머리·복장·대표 무기, 굵은 윤곽선, 셀 명암, 대기 호흡 동작을 적용했습니다.
- **패널**: 스트레스 아래의 캐릭터 대사와 대사 데이터 필드를 제거했습니다.
- **스킬**: 12명 모두 고유 기술 4개를 사용합니다. 전열의 중열 공격, 근접의 명중 후 표식 공격, 중후열의 출혈 공격, 지원의 자가 치료를 추가하고 수감자별 표시명을 적용했습니다.
- **조작**: 기술 단축키 1~4, 작은 화면에서 2×2 기술 카드 배치. 이동·방어·대기는 별도 공통 행동입니다.
- **기존 기능**: 12명 중 4명 편성, 행동 클로즈업·무기 동작·피격·회피·지원 효과, 연출 건너뛰기와 모션 감소는 유지했습니다.

모델은 공식 스프라이트를 추출한 것이 아닌 독자적인 2D SD 팬 모델입니다. 기술·역할·수치는 이 전투 게임을 위한 각색입니다.

## 검증

테스트 31개 통과(100개 난수 초기값 전체 전투 포함), 프로덕션 빌드 성공.
12명 모두의 네 번째 기술, 명중 후 표식·출혈·전열 자가 치료·위치 제한을 검사했습니다.
개발 서버와 단일 HTML의 오프라인 렌더링 모두 실제 Chromium에서 모델·대사 제거·4개 기술·1~4 단축키·편성·클로즈업을 확인했고 5라운드·수감자 4명 생존으로 승리했습니다.
360/390/768/1024/1440px 화면과 모션 감소 검증 통과, JS 런타임 오류 없음.
클라우드 정책상 file:// 탐색은 제한되어 단일 HTML을 직접 로드한 검증과 구분합니다.

ZIP의 `source/`에는 수정 가능한 소스와 README, 조사 기록, 전투 명세, 변경 기록이 있습니다.
