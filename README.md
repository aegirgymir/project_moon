# 골목의 잔향 v0.2 — 수감자와 행동 클로즈업

《림버스 컴퍼니》 수감자 12명 중 4명을 편성하는 위치 기반 턴제 전투 팬 프로토타입입니다.
수감자는 원작 이름과 특징을 반영한 SVG 팬 일러스트로 재해석했습니다.
기술·전술 역할·대사·능력치는 이 게임을 위한 각색입니다.

## 바뀐 내용

- 이상·파우스트·돈키호테·료슈·뫼르소·홍루·히스클리프·이스마엘·로쟈·싱클레어·오티스·그레고르 중 4명 편성.
- 기본 전열→후열: 돈키호테·료슈·이상·파우스트.
- 각자의 무기·머리 모양·복장·표시 번호를 반영한 SVG 팬 일러스트와 초상화.
- 아군과 적의 매 행동에 카메라 확대, 레터박스, 무기 동작, 타격 궤적, 피격·회피·지원 효과.
- 행동 중 중복 입력 방지와 적 대기. Space/Escape로 연출 건너뛰기, 카메라 버튼으로 연출 끄기.
- 빠른 재생과 모션 감소 설정 대응. 초기화 시 선택한 편성 유지.

`1`~`3`: 기술 / `←`·`→`: 대상 / `Enter`: 실행 / `M`: 이동 / `G`: 방어 / `W`: 대기.
ZIP의 `source/`에 수정 가능한 소스와 조사 기록·전투 명세·변경 기록이 포함되어 있습니다.

## 검증

테스트 25개 통과(100개 난수 초기값의 전체 전투 포함), 프로덕션 빌드 성공.
개발 서버와 단일 HTML의 오프라인 렌더링 모두 실제 Chromium에서 편성·동작·카메라 확대·양측 28회 연출·건너뛰기·입력 잠금·재시작을 확인하고 5라운드·수감자 4명 생존으로 승리했습니다.
360/390/768/1024/1440px 화면과 모션 감소를 검증했고 JS 런타임 오류가 없었습니다.
클라우드 정책상 file:// 탐색은 제한되므로 단일 HTML 원문을 직접 로드한 검증과 구분합니다.
